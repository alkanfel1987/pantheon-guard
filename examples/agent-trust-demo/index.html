Manipulation is not a property of text alone

The same phrase is pressure on a sales page and a cry for help in a first-person message. pantheon-guard judges utterances in context — never identities — and gives agent pipelines an explainable decision: pass, warn, or hold. Every verdict unfolds into the exact rule, idiom or hypothesis that fired.

lexical rules, the idiom registry and the distress veto run live in your browser — real library code, your own text. Semantic NLI scores are recorded from real local runs (~81 ms/hypothesis, laptop CPU) until you load the local model; the pipeline session is scripted and labeled as such.

2 · scripted pipeline session — agents, reputation, provenance

scripted demo · verdict logic real

Reputation = aggregate of this session's verdicts per agent, with decay. It scores behavior history of software agents — never humans. Unsigned external content is held at the provenance gate, not "detected as fake": fact-checking and AI-authorship detection are explicitly out of scope.

what this is not

  • Not a fact-checker. Truth requires world knowledge; we flag delivery pressure and gate provenance instead.
  • Not an AI-text detector. Authorship classifiers are unreliable; we verify the source, not guess the author.
  • Not a person scorer. Reputation applies to software agents and public channel behavior only — a rejected-by-design boundary.
