# Архитектурный принцип: Claude строит guard, но НЕ является guard

> Зафиксирован 2026-06-10. Точка отсчёта для всех решений об архитектуре детекции.

## Вопрос, из которого родился принцип

«Если большая языковая модель (Claude) понимает смысл идиом, манипуляций, переносного значения — может, просто использовать её как детектор в проде?»

Технически — да, LLM-as-detector реален. Но это нарушает требования, на которых стоит guard.

## Разграничение

### LLM (Claude) НЕ компонент guard в проде

| Свойство | Claude как детектор | Локальная модель + правила |
|---|---|---|
| Суверенитет | API, отключаемый под санкциями → guard мёртв | Локально, офлайн навсегда |
| Стоимость | Квота/деньги за каждый вызов | Бесплатно после скачивания |
| Объяснимость | Чёрный ящик, механически не объясним | Порог + гипотеза + правило, прозрачно |
| Детерминизм | Недетерминирован | Воспроизводимый аудит-трейл (для регуляторики) |

Guard намеренно НЕ является обёрткой Claude API. Anthropic строит максимально способный чёрный ящик; guard = минимально достаточный прозрачный белый ящик. Разные цели.

### LLM не имеет достоверного доступа к собственному механизму

«Спросить Claude, как он детектирует» → правдоподобная пост-рационализация, не реальный алгоритм. Модель не интроспектирует свои веса. Строить детектор на само-описании LLM нельзя — только на реальных замерах локальных моделей (как `examples/asurya-semantic-probe.js`, `idiom-semantic-probe.js`).

### Где LLM реально полезен — как строитель, не деталь

1. **Учитель/разметчик** — формулирует принцип-гипотезы (NLI), размечает данные для калибровки локальной модели.
2. **Генератор adversarial-примеров** — придумывает атаки для тестового набора (Асура-векторы).
3. **Эталон для дистилляции** — разбор смысла LLM → обучающий сигнал для маленькой локальной модели.

## Формула

**Выжать понимание из LLM в автономный артефакт — НЕ вставить LLM в guard.**

Claude проектирует и размечает → локальная модель (mDeBERTa + реестр устойчивых выражений + принцип-гипотезы) исполняет в проде. Результат переживает отключение Claude и предъявим регулятору.

## Следствия для текущего пути

- Семантический слой = локальный zero-shot NLI (mDeBERTa-XNLI), не вызовы Claude.
- Принцип-гипотезы формулирует Claude, но они становятся статичным конфигом, не рантайм-зависимостью.
- Реестр идиом — curated человеком+Claude словарь, исполняется локально.
- Любой замер — на реальной локальной модели, не на само-аттестации Claude.
